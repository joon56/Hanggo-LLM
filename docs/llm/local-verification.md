# 로컬 AI 검증 기록

검증일: 2026-09-30. RTX 4060 Laptop 8GB, RAM 32GB, Windows, Ollama 0.34.4.

## 구현 검증

- `npm.cmd run verify`: 단위 테스트 258개, 타입 검사, 빌드, 브라우저 테스트 10개 통과. 테스트 자료 82개 형식·수동 계산 검증 통과.
- Ollama 연결, 네 기능의 로컬 출처 표시, API 키 없는 요청, 취소·시간 초과·수동 대체를 확인했습니다.
- 클라우드 별칭 모델은 기록을 보내기 전에 차단합니다. Ollama 0.34.4 이상에서 입력 잘림·문맥 이동을 막습니다. 실제 문맥 초과 요청은 원문 전체가 남은 수동 초안으로 전환됐습니다.
- 독립 코드 검토에서 발견된 설치 경로 공백 처리·다운로드 자식 프로세스 정리 문제를 수정했습니다.
- 실제 Chrome 화면에서 Qwen3.5로 네 기능 생성, 상담일지 승인·재열람, 보호자 기록 저장, 보호소 프로필 확정·저장을 확인했습니다. 브라우저 오류·외부 요청·모바일 가로 넘침이 없었습니다. 각 기능 한 사례 검사이며 모든 사용자 입력의 검증을 뜻하지 않습니다.

## 실제 음성 처리

Whisper medium Q5_0을 CPU로 실행했습니다. Windows Heami 합성 음성 3.75초:

- 원문: `오늘 초코가 앉아를 세 번 연습했습니다.`
- 결과: `오늘 초코가 앉아를 3번 연습했습니다.`
- HTTP `/api/transcribe`: 9.18초. 요청 임시 파일 삭제 확인.
- Chrome 가상 마이크 → MediaRecorder → 받아쓰기: 9.95초. 받아쓰기 확인 전 일지 생성 차단, 확인 후 활성화 확인.
- 최종 Qwen3.5 연결에서 녹음 → 받아쓰기 9.22초 → 상담일지 생성 1.72초까지 확인했습니다. `trainer_summary_voice` 출처와 `ollama` 모델 출처가 유지됐습니다.
- 실행 중 취소·시간 초과도 실제 음성 실행기로 확인했습니다. 중단 후 임시 녹음 파일이 남지 않았습니다.

합성 음성 한 사례의 결과입니다. 실제 마이크·배경 소음·긴 발화·이름 인식 품질은 사용자 테스트가 필요합니다.

## 텍스트 모델 비교

문맥 크기 8192, temperature 0, seed 42, 추론 모드 끔으로 평가했습니다. `qwen3.5:9b`는 `ollama ps`에서 100% GPU 실행을 확인했습니다. 측정 당시 전체 GPU 메모리 사용량은 약 6.4GiB였습니다.

최종 설정의 전체 82개 실제 모델 평가:

| 기능 | 자동 조건 통과 | 평균 처리 시간 |
|---|---:|---:|
| 상담일지 | 28/30 | 1.97초 |
| 보호자 기록 | 25/28 | 4.82초 |
| 상담 전 브리핑 | 12/12 | 1.16초 |
| 보호소 프로필 | 9/12 | 2.75초 |
| 전체 | **74/82** | |

시간은 모델이 로딩된 상태에서 짧은 가상 자료를 처리한 값입니다. 처음 실행·긴 입력·동시 PC 작업에서는 달라집니다.

미통과 사례:

- 상담일지 `N13`, `N14`: 출처가 모호한 짧은 메모의 분류가 기대와 다름.
- 보호자 `poop`: 수동 대체 및 불필요한 안전 표시. `bite`: 불필요한 추가 안전 표시. `unrelated`: 수동 대체.
- 보호소 `health`, `breed-inference`, `unsupported-guarantee`: 원문·분류 검증 실패로 기존 규칙 초안으로 대체.

상담일지는 원문 문장을 선택하게 해 숫자·띄어쓰기 변형을 막았습니다. 브리핑은 코드로 계산한 근거 ID만 선택하게 제한했습니다. 원문·숫자·안전 검증은 유지하며, 실패를 성공으로 표시하지 않습니다. 짧은 메모의 의미 분류와 불필요한 안전 표시는 여전히 사람 검토가 필요합니다.

최종 설정으로 고정 16개 사례를 각각 재실행한 비교:

| 모델 | 자동 조건 통과 |
|---|---:|
| 기존 `qwen2.5:3b` | 6/16 |
| 선정 `qwen3.5:9b` | **15/16** |

새 모델의 16개 실행에서는 `N15`에 불필요한 방법 검토 표시가 붙었습니다. 전체 82개 실행에서는 같은 사례가 통과했습니다. 같은 seed·temperature라도 실행 결과가 완전히 고정되지는 않았으므로, 이 결과를 무오류 보장으로 해석하면 안 됩니다.

초기 지시문에서는 기존 모델 4/16, 새 모델 11/16이었습니다. 최종 비교는 두 모델 모두 같은 보완된 지시문·스키마를 사용합니다. 상세 원문·결과는 로컬 `test-output/local-모델명-smoke.json`, `-all.json`에 있습니다.

자동 PASS는 해당 사례의 기대 조건을 충족했다는 뜻입니다. 모든 원문 사실의 완전한 추출이나 실제 상담 품질을 보장하지 않습니다.
