# 로컬 전용 정리·베타 시연 검증

검증일: 2026-09-30. Windows, Node.js 24.16.0, Ollama 0.34.4, RTX 4060 Laptop 8GB, RAM 32GB.

## 변경 범위

- OpenAI SDK와 호출 구현, 공급사 선택 분기, 키·외부 모델 설정을 제거했습니다. 현재 실행은 Ollama·Whisper만 사용합니다.
- `.env`의 이전 공급사 설정은 값을 출력하지 않고 제거했습니다. 가상 설정 파일로 로컬 모델·접근 비밀번호 등 관련 없는 값이 유지되는지 확인했습니다.
- 기존 저장 기록은 계속 읽습니다. 과거 `openai` 출처는 호환용으로 남기고 화면에 “이전 AI”로 표시합니다.
- 모델·추론 프롬프트는 변경하지 않았습니다. 이전 모델 품질 측정은 [로컬 검증 기록](local-verification.md)에 있습니다.

## 자동 검증

- `npm.cmd run verify`: 종료 코드 0. 단위 테스트 **27개 파일·258개**, 타입 검사, 배포 빌드, 모의 Playwright **10개** 통과.
- 비밀번호 서버의 평가 CLI가 로그인 후 준비 상태를 확인하도록 보완했습니다. 실제 인증 서버와 CLI를 연결하는 회귀 검사 추가 후 최종 `npm.cmd test`는 **28개 파일·259개**, 타입 검사도 통과했습니다.
- 테스트 자료 30개 형식 검증, 보호자·브리핑·보호소 52개 형식/수동 계산 검증 통과. 이 82개 검사는 실제 모델 품질 평가가 아닙니다.
- `beta:check` 회귀 검사 6개: 기본 읽기 전용, 원격 화면 차단, 수동 대체 실패 판정, 화면 프록시 기능 확인, 이전 모델 설정 감지, 예열 실패 후 자체 로그인 세션 종료.
- 실제 `npm.cmd run beta:check` 성공. `--warmup` 가상 상담 요청 성공, 5.9초, 브라우저 저장 없음.
- 설치된 의존성의 `npm.cmd ls openai --depth=0` 결과는 빈 목록입니다.
- 독립 코드 검토에서 차단 이슈 없음. 설치 시 `.env` 변경 범위를 설명하는 문구를 보완했습니다.

## 실제 로컬 브라우저 확인

별도 Chrome 테스트 컨텍스트에서 가상 자료로 실행했습니다. 사용자 브라우저 저장소에는 기록을 추가하지 않았습니다.

| 기능 | 입력 | 생성 시간 |
|---|---|---:|
| 상담일지 | 오늘 1.5미터 거리를 두고 기다리는 모습을 관찰했습니다. | 2.22초 |
| 보호자 일상 기록 | 초코 산책 30분 | 4.30초 |
| 상담 전 브리핑 | 직전 저장한 초코 기록 | 0.84초 |
| 보호소 프로필 | 사람에게 다가왔습니다. 다른 개를 보면 짖음. | 3.16초 |

네 요청 모두 `qwen3.5:9b`, `mode: ollama`, `fallbackUsed: false`였습니다. 상담일지 승인·새로고침·재열람, 보호자 저장, 자료 부족 표시, 보호소 확정·저장을 확인했습니다. 브라우저 오류와 외부 브라우저 요청은 없었으며 모바일 가로 넘침도 없었습니다.

합성 음성을 Chrome 가상 마이크로 녹음한 결과:

- 입력: `오늘 초코가 앉아를 세 번 연습했습니다.`
- 받아쓰기: `오늘 초코가 앉아를 3번 연습했습니다.` — Whisper medium Q5_0 CPU, **9.96초**.
- 사람의 원문 확인 전 생성 차단, 확인 후 상담일지 생성 — Qwen3.5, **1.73초**.
- `trainer_summary_voice` 출처 유지, 수동 대체와 브라우저 오류 없음.

이는 기능별 가상 사례 검사입니다. 실제 마이크·잡음·말투와 모든 입력의 품질을 보장하지 않습니다. 회의 전 [시연 대본](../testing/beta-test-script.md)의 P00과 음성 단계를 직접 확인하고 [결과표](../testing/beta-results.csv)에 당일 결과를 기록하세요.
