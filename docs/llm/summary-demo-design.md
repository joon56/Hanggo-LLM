# 상담 후 요약 데모 설계

## 확정 범위

사용자가 승인한 흐름: 짧은 음성 요약 또는 텍스트 → 원문 확인·수정 → 일지 초안 → 근거 확인 → 훈련사 승인.
구현 위치: 이 폴더의 독립 테스트 앱. 공급사는 이후 결정하며 이번에는 데모만 사용한다.

## 동작

- React·TypeScript·Vite로 로컬에서 실행. 서버·외부 AI·Firebase 연결 없음.
- 브라우저 MediaRecorder로 최대 60초 녹음하고 로컬에서 재생한다. 권한 거부, 미지원 환경, 너무 짧은 녹음을 안내하며 마이크 트랙을 정리한다.
- 음성은 메모리에만 두고 교체·새 기록·페이지 종료 시 해제한다. 서버 업로드·음성 저장 없음.
- 실제 STT는 연결하지 않는다. 녹음 재생 후 사용자가 받아쓰기를 입력한다. 예시는 명시적인 버튼으로만 불러온다. 녹음이 예시 텍스트로 자동 변환된 것처럼 표시하지 않는다.
- 일지 생성은 입력 문장 그대로의 인용을 규칙으로 분류하는 데모다. 의미 추론·새로운 사실·레슨 추천은 하지 않는다. 모든 화면과 내보내기에 데모임을 표시한다.
- 반려동물 이름·상담 날짜·훈련사 이름은 기록 메타데이터다. 별도 상담 발언으로 취급하지 않는다.
- 입력 출처는 trainer_summary_text 또는 trainer_summary_voice. 모두 훈련사의 사후 요약이며 실제 상담 녹취가 아니다.
- 분류: 보호자 보고, 훈련사 관찰, 안내, 합의한 과제, 추가 확인. 불명확한 문장은 추가 확인에 남긴다.
- 초안 문장마다 원문 인용을 표시하고 클릭하면 해당 문장을 강조한다. 사용자는 분류·문구를 수정하고 항목을 제거할 수 있다.
- 안전 신호는 보수적인 키워드 검사로 표시한다. 추출된 과제는 안전 또는 강압적 방법 검토 신호가 있으면 검토 대상으로 분류하고 과제로 내보내지 않는다. 신호는 사용자가 숨기거나 해제할 수 없다.
- 과제는 원문에 있는 내용의 추출만 허용한다. 24개 레슨 카탈로그는 제공되지 않았으므로 추천·ID 연결은 없다.
- 초안 생성 후 원문·메타데이터가 바뀌면 초안을 무효화한다. 승인 전 직접 확인 체크 필요.
- 승인 시 이 브라우저에 저장한다는 안내를 제공한다. 저장 실패는 성공으로 표시하지 않는다. 기록 재열람, JSON 다운로드, 개별 삭제 제공. 자동 외부 전달 없음.
- 텍스트·초안·이름 등은 콘솔에 로깅하지 않는다. 외부 폰트·이미지·분석 도구도 사용하지 않는다.

## 경계와 확장

`src/domain/notes.ts`: 원문·초안·검증의 공통 타입과 순수 규칙. `src/domain/storage.ts`: 승인된 데모 기록의 브라우저 저장. `src/hooks/useRecorder.ts`: 녹음 수명주기. `src/App.tsx` 및 components: 입력·검토·승인 UI.
향후 STT는 입력 원문을 만드는 별도 단계로, LLM은 서버를 호출하는 일지 생성 어댑터로 추가한다. 클라이언트에 API 키를 넣지 않는다. 전체 상담 전환 시 다중 화자·구간 시간·긴 음성 작업 관리·동의가 추가로 필요하다. 이번에는 미래 기능을 미리 구현하지 않는다.

## 화면

훈련사용 차분한 문서 편집 화면. 따뜻한 회색 바탕, 흰 작업지, 짙은 글자, 옅은 녹색 상태 표시. 좌측 간단한 기록 목록, 중앙 입력, 우측 검토 결과. 좁은 화면에서는 세로 배치. 큰 녹음 버튼과 명확한 단계 안내. 키보드 조작과 상태 알림 지원.

## 성공 기준

1. 입력·예시로 초안을 만들고 원문 근거를 확인·수정할 수 있다.
2. 입력을 바꾸면 이전 초안을 승인할 수 없다.
3. 안전·방법 검토 신호가 있으면 과제 전달을 막는다.
4. 승인 전에는 기록을 영속 저장하지 않는다. 승인 후 재열람·다운로드·삭제 가능.
5. 마이크 권한 거부·녹음 종료·초기화·화면 종료에서 트랙과 메모리 정리.
6. 자동 테스트, 타입 검사, 프로덕션 빌드, 실제 브라우저 데모 흐름을 확인한다.

## 제한

실제 STT·LLM 성능, 24개 레슨 매핑, 운영 인증·권한·Firestore·APK는 검증 대상 밖이다. 규칙 분류는 임상적 판단이나 운영용 안전 판별이 아니다. 원문에 없는 내용을 사용자가 직접 추가한 경우 사용자의 수정임을 표시한다.
