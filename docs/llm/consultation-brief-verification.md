# 상담 전 브리핑 검증 · 2026-10-07

## 변경 범위

보호자 기록과 사용자가 직접 선택한 확정 상담일지로 핵심 상황, 변화·주의점, 이번 상담에서 확인할 일을 정리한다. 날짜·원문·상담 근거 시간, 최대 3개의 확인 질문을 제공한다. 무료 로컬 Ollama를 사용하며 카메라·녹화 구현은 이번 변경에 포함하지 않았다.

## 자동 검증

| 검증 | 결과 |
|---|---|
| `npm.cmd test -- --maxWorkers=2` | 42개 파일, 450/450 통과 |
| `npm.cmd run build` | 프런트엔드·서버 타입 검사와 빌드 통과. JS 청크 503.52 kB로 Vite의 500 kB 경고 발생 |
| `npm.cmd run llm:eval:workspace -- --feature brief` | 코드 기반 fixture 12/12 통과. 실제 모델 평가와 구분 |
| `npm.cmd run test:e2e -- e2e/brief.spec.ts e2e/workspace.spec.ts` | Chrome 5/5 통과. 기록 선택·3줄·근거·질문·JSON 내보내기·자료 없음 확인 |

최종 단위 테스트는 작업자 수를 2로 제한해 실행했다. 앞선 기본 병렬 실행에서는 변경하지 않은 보호자 저장 용량 및 UI 테스트 2건이 5초 제한을 넘었다. 테스트 제한 시간을 늘리지는 않았다.

회귀 테스트에는 다른 반려동물의 안전 신호, 미래·날짜 불명 기록, 상담 자료 변경·삭제·확정 취소, 생성 중 선택 변경·취소, 늦은 응답, AI 실패 대체 결과, 긴 원문의 잘림 표시를 포함했다. 서버 상담은 생성 전후 확정 상태와 revision을 검증한다. 브라우저의 기존 상담일지도 성공·대체 처리 전 다시 읽어 변경 여부를 확인한다.

## 실제 로컬 모델·화면

- 모델: `qwen3.5:9b`, 외부 AI API 사용 없음.
- 별도 임시 서버 저장소와 Chrome 컨텍스트에 가상 보호자 기록 6건 및 확정 상담일지 1건을 준비했다. 기존 사용자 자료는 변경하지 않았다.
- 최종 1건 측정: **12,199 ms**, AI 성공, `fallbackUsed: false`. 단일 사례 측정이며 평균·최대 지연을 뜻하지 않는다.
- 실제 서버의 확정 상담을 명시적으로 선택해 생성했다. 핵심 3줄, 상담 과제·후속 확인·대응 후 반응 질문, 날짜·원문 근거, JSON 다운로드를 확인했다.
- 데스크톱 및 폭 390 px 화면에서 확인했다. 가로 넘침과 브라우저 실행 오류가 없었다.
- 잘못된 revision 및 다른 반려동물의 상담 선택은 HTTP 409로 거절됨을 별도 API 검사로 확인했다.

가상 기록의 핵심 상황에는 “초인종 소리에 3분 짖었어요. 매트로 이동시킨 뒤 짖음이 줄었어요.”라는 원문이 표시됐다. 변화에는 최근 3건/직전 1건이 **기록 횟수**로 표시됐고, 확인 질문에는 이전 과제 시도 여부, 다음 상담에서 확인하기로 한 반응, 대응 뒤 반응까지 걸린 시간이 각각 연결됐다. 과제를 수행했다고 추정하지 않았다.

## 녹화 테스트의 별도 한계

전체 브라우저 테스트 실행은 **14/16 통과**였다. 탭 및 가상 카메라 녹화 2건은 첫 WebM 업로드가 1바이트 `0x1A`여서 HTTP 400 `MEDIA_INPUT`, `First recording chunk must contain WebM header.`로 거절됐다.

변경 전 기준 커밋 `4e34db2`의 별도 checkout에서 아래 테스트를 다시 실행했고, 같은 첫 업로드 내용과 오류를 확인했다.

```powershell
npm.cmd run test:e2e -- e2e/consultation.spec.ts --grep 'Chrome actual worklet'
```

따라서 전체 브라우저 검증을 통과했다고 볼 수 없다. 브리핑 관련 5개 시나리오는 최종 수정 후 모두 통과했다. 카메라·녹화 문제는 사용자 요청에 따라 보류했고, 이번 브리핑 개선으로 해결했다고 주장하지 않는다.

## 자료와 품질 한계

- 상세 근거는 보호자 사건 최대 24개, 상담 항목 최대 12개, 원문 400자, 상담 항목당 시간 근거 2개로 제한한다. 생략·잘림은 화면에 표시한다. 수치 집계는 해당 기간의 조건에 맞는 전체 사건을 사용한다.
- 모델에는 최대 48개 사실과 사실별 최대 160자 텍스트를 전달한다. 전체 전사를 다시 보내지 않는다. AI는 기존 근거 ID를 선택하고 코드가 사실·질문을 표시한다.
- 기록 건수는 실제 행동 빈도나 진단이 아니다. 미기록 기간과 과제 수행 여부는 미확인으로 남긴다.
- 기존 짧은 상담·보호자 기록은 해당 브라우저 저장소에, 상세 상담은 로컬 서버에 있다. 다른 기기와 자동 공유하지 않는다.
- 실제 보호자 자료, 장기간 다양한 기록의 품질, 모든 입력의 무오류 동작을 보장하는 검증은 아니다.
