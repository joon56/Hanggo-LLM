# 실시간 상담 검증 기록

## 실제 로컬 모델과 60분 자료

2026-10-07, RTX 4060 Laptop GPU 8GB, 선택 모델 `whisper-turbo`.
`scripts/verify-live-consultation.ts`로 60분 합성 자료를 실제 Express API·디스크·GPU·Ollama에 연결했다.

| 확인 항목 | 결과 |
|---|---|
| 입력 길이 | 3,600,000ms |
| 음성 구간 | 10초 × 360개 |
| 화면·음성 WebM | 2,658,576 bytes, 단순 합성 화면·대부분 무음 |
| 실제 전사 발언 | 시작, 30분, 59분 50초 |
| 전사 처리 | 세 발언 모두 원문 내용 보존, 나머지는 무음 처리 |
| 일지 | 9개 항목, 세 발언의 근거 ID 포함, fallback 없음 |
| 검토 승인 | 성공 |
| 녹화 탐색 | HTTP Range 206, 요청한 128 bytes 반환 |
| 녹화 파일 길이 | FFprobe 3,600.008초 |
| 재로딩 | 새 저장소 인스턴스로 360구간·ready·승인 상태 복원 |
| 가속 검증 소요 | 약 77초 |

이는 **60분 자료의 가속 처리 시험**이다. 60분 동안 실제 브라우저 화면 공유를 유지한 시험은 아니다.
단순 화면·대부분 무음 자료이므로 복잡한 화상 화면의 녹화 용량, 60분 연속 발화의 추출 품질,
장시간 브라우저 메모리와 발열을 입증하지 않는다.

## 실제 브라우저와 로컬 GPU 연결

Chrome의 실제 AudioWorklet·MediaRecorder와 빌드된 앱, Express 저장 API,
Whisper large-v3-turbo GPU, Ollama를 연결했다. 화면은 합성 canvas이며 탭 오디오와
마이크 입력에는 서로 다른 합성 한국어 음성을 주입했다. 물리 마이크나 브라우저 공유 선택창을
직접 조작한 시험은 아니다.

- 약 24초 녹화, WAV 3구간: 탭과 마이크의 두 발언을 모두 인식했다.
- 중요 장면 저장, WebM 재생·12초 위치 이동, 상세 일지 생성·검토 승인 성공.
- 브라우저 JavaScript 오류 없음. 결과·스크린샷은 `.tmp/real-browser`에 보관한다.
- 10초 경계에 걸친 문장의 끝 `하겠습니다.`가 다음 구간에도 나타났다.
  현재는 연속된 10초 구간을 독립 인식하므로 문장 조각이나 중복이 남을 수 있다.
  구간 인접 문장을 자동 삭제하면 실제 반복 발언도 지울 수 있어 그대로 보존한다.
  승인 전 녹화와 전사를 비교하고, 중복 구간은 원문에서 수정한 뒤 일지를 재생성한다.

## 테스트가 찾은 오류와 수정

- 음성 파일 저장과 전사 메타데이터 저장 사이 실패: 하나의 메타데이터 저장으로 연결하고 재시도 복구를 추가했다.
- 업로드와 종료 동시 요청: 최신 전사 길이 검증과 상태 전환을 같은 잠금 안에서 처리한다.
- 실패 상태 저장 오류가 다음 전사까지 막는 문제: 작업 실패를 분리하고 미완료 상태로 마무리한다.
- 손상된 상담 하나가 모든 상담 복구를 막는 문제: 저장 자료 구조를 검증하고 손상된 항목을 분리한다.
- 반복 발언이 일지에서 제곱으로 늘어나는 문제: 같은 출처 안의 중복만 제거한다.
  500개 반복 발언 시험은 21번 생성 요청, 500개 일지 항목, 500개 근거로 완료했다.
- 음성 실행기 시작 실패 후 대기 지속: 이미 종료된 프로세스 참조를 해제한다.
- 무음에서 Whisper가 문장을 출력하는 문제: 실제 모델 요청 전 PCM 무음 검사를 적용한다.
- 브라우저 오디오 처리·녹화 실패: `CAPTURE_INTERRUPTED`를 저장하고 불완전 기록의 승인을 막는다.
- 숨김 폴더 아래에서 빌드 앱의 첫 화면 제공 실패: 정적 루트를 기준으로 `index.html`을 제공한다.
- 전사를 고치고 저장하지 않은 상태의 승인: 수정 저장 또는 취소 전 일지 생성·승인을 차단한다.
- 모델 준비 도중 오디오 장치가 끊기는 경우: 녹화 직전 입력 상태를 다시 확인하고 불완전 기록으로 남긴다.
- 다른 창에서 바뀐 일지의 승인: 서버가 검토한 일지 버전을 비교한다. 다르면 최신 자료를 다시 불러와 재검토를 요구한다.
- 마지막 메타데이터 저장의 일시 실패: 종료 정보를 보존해 재시도한다. GPU·AI 사용권은 한 번만 반환하고, 이후 시작한 상담에는 영향을 주지 않는다.
- 녹화 없이 전사·메모만 남은 기록: JSON 내보내기를 제공한다.

## 검증 상태의 구분

- `npm.cmd run verify`: 단위 테스트 354개, Chrome 테스트 13개, 타입 검사·빌드, 테스트 자료 82개 통과.
  브라우저 테스트는 실제 Worklet·WebM과 로컬 저장 API를 사용하되 모델 응답은 대체한다.
  실제 모델 연결은 위 별도 GPU 시험으로 확인했다.
- 테스트 출력의 `NO_COLOR`/`FORCE_COLOR` 경고는 실행 환경의 색상 설정 충돌이다. 테스트 실패나 앱 런타임 오류는 없었다.
- 모델 다운로드·SHA-256·GPU 실행 및 짧은 합성 음성 비교: 완료. [측정값](speech-comparison.md)
- 상담 백엔드 검토: 저장·종료·작업 큐·근거 검증 문제를 수정 후 재검토 통과.
- 전체 기능 회귀와 합성 입력 브라우저 capture 검증을 완료했다.
- 사용자 실제 마이크·발음·실제 상담 화면의 인식 품질은 [시연 대본](../testing/live-consultation.md)으로 확인한다.

시험 자료와 상세 실행 결과는 Git 제외 폴더 `.tmp/live-validation`에 보관한다.
