## 자동 테스트 범위

- 원문 인용 보존, 소수점 문장 분리, 출처 없는 숫자 추가 거부.
- 안전·강압적 방법 신호의 보존, 원문과 편집 내용의 위험 신호 검사, 과제 승인 차단.
- 미확정·취소된 과제와 일상 서술의 과제 오분류 방지 사례.
- 검토 체크와 메타데이터 검증, 승인 시 스냅샷 생성.
- 저장·재열람·삭제, 자료 손상·저장 공간 오류, 50개 한도에서 기존 기록 보존, 음성 저장 제외.
- 초안 원문 변경 시 승인 무효화, 녹음 실패 뒤 텍스트 출처 보존.
- 마이크 권한 거부, 60초 제한, 3초 미만 처리, 늦은 권한 응답 취소, 마이크 트랙·재생 URL 정리.
- 브라우저에서 예시 입력, 근거 확인, 승인, 새로고침 후 재열람, JSON 다운로드, 삭제.
- 390px 모바일 화면의 안전 안내와 초안 무효화.
- 브라우저 가상 오디오 장치로 실제 MediaRecorder 녹음·재생 URL 생성·새 기록 초기화 확인. 녹음 후 받아쓰기 텍스트를 자동 생성하지 않는 것도 확인.

## 검토 중 수정한 문제

1. 51번째 저장에서 가장 오래된 기록이 자동 삭제되던 동작을 저장 거부·안내로 변경했다.
2. 녹음 시작만으로 음성 출처를 부여하던 동작을 수정했다. 성공한 녹음이 있는 상태에서 직접 받아쓴 경우에만 음성 요약 출처로 표시한다.
3. 초안 편집에서 추가된 위험 표현도 경고·검증·승인 스냅샷에 반영한다.
4. 확정되지 않았거나 취소한 과제 표현을 추가 확인으로 분류한다.

## 범위의 한계

- AI 공급사를 연결하지 않았다. 자동 STT·LLM 생성·실제 레슨 추천은 검증하지 않았다.
- 규칙 분류는 데모이며 실제 의미 이해, 안전 신호의 완전한 탐지, 새로운 사실의 완전한 차단을 보장하지 않는다.
- 실제 사람의 마이크 음질, 모바일 실기기, Android APK, 훈련사의 실제 상담 사용성은 미검증이다.
- 브라우저 테스트의 녹음은 가상 오디오 장치다. 실제 음성을 수집·전송하지 않았다.
- 운영 Firebase 인증·권한·Functions·Firestore·로그·기능 플래그는 이번 독립 데모에 연결하지 않았다.
