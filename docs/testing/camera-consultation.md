# 카메라 상담 베타 시연 대본

목표: 내 카메라로 반려동물의 행동과 내 설명을 함께 녹화하고, 음성 전사·영상 관찰·일지의
근거가 같은 녹화 구간을 가리키는지 확인한다. 원격 훈련사 접속은 다음 단계다.

## 준비

1. Windows Chrome/Edge에서 로컬 앱 `http://127.0.0.1:5173/`를 연다.
2. 카메라가 반려동물의 몸과 주변 공간을 볼 수 있도록 놓는다. 내 얼굴 촬영은 필수가 아니다.
3. Ollama와 `qwen3.5:9b`, GPU `whisper-turbo`를 준비한다. 이 PC에 설치된 모델을 사용한다.
4. 실시간 상담 화면의 `녹화 입력`에서 카메라를 선택한다. 이름은 `카메라 시연`, 훈련사는 `시연자`로 입력한다.
5. 녹화·로컬 AI 처리 동의를 확인한다. `카메라·마이크 녹화 시작`을 누르고 브라우저의 카메라·마이크 권한을 허용한다.

## 1. 카메라와 내 목소리 확인 — 약 30초

미리보기에서 손을 움직여 본다. 아래 문장을 자연스럽게 읽는다.

> 지금부터 카메라 상담 기록을 시작합니다. 오늘은 영상과 제 설명이 함께 기록되는지 확인합니다.
> 아직 훈련 과제는 정하지 않았습니다.

확인:

- 화면 공유할 탭을 고르는 창 없이 실제 카메라 화면이 나온다.
- 음량 표시가 반응하고, 약 10초 분량이 모인 뒤 전사가 나온다.
- 스피커에서 내 마이크 소리가 반복 재생되지 않는다.

## 2. 시각과 말의 근거 확인 — 약 1분

화면에 물건을 하나 보여주고 `현재 장면 표시`를 눌러 시간을 고정한다.
물건을 천천히 왼쪽에서 오른쪽으로 옮긴 뒤 메모를 작성·저장한다.

> 지금 화면에 물건을 보여주고 있습니다. 왼쪽에서 오른쪽으로 옮기겠습니다.

실제로 화면에 보이는 행동만 말한다. 반려동물이 보이면 그때의 자세와 위치를 덧붙인다.

> 지금 보이는 자세와 위치를 기록해 주세요. 이 행동의 원인은 아직 확인하지 않았습니다.

확인:

- 중요 순간 시각은 표시 버튼을 누른 녹화 경과 시간이다. 메모 저장 시점으로 밀리지 않는다.
- 원하는 순간을 놓쳤으면 종료 후 원본을 재생해 해당 시각에 새 메모를 남긴다.
- 관찰할 행동이 없으면 있다고 꾸며 말할 필요가 없다. 빈 관찰 결과도 정상이다.

## 3. 종료와 영상 분석

1. 녹화를 종료하고 마지막 저장·전사가 끝날 때까지 기다린다.
2. 원본을 재생해 카메라 영상과 목소리가 모두 들어 있는지 확인한다.
3. `장면 분석 시작`을 누른다. 진행 중에는 모델 준비와 장면별 처리 상태를 확인한다.
4. 각 관찰의 근거 프레임·시각을 보고 원본의 같은 위치로 이동한다.

확인:

- 전사 완료 후 영상 모델을 실행한다. 녹화 중 영상 분석이 동시에 실행되는 흐름이 아니다.
- 기본 시간 간격의 장면과 중요 메모 주변 프레임을 분석한다. 전체 프레임을 분석하지 않으므로
  장면 사이의 짧은 행동은 빠질 수 있다.
- 사각형·물건만 있는 장면에 반려동물의 행동이나 심리가 만들어지지 않는지 확인한다.
- 시각은 분석한 프레임의 위치다. 행동 시작·끝이나 보상까지 걸린 시간을 자동 측정한 값이 아니다.
- 전사는 약 10초 구간의 시간이다. 음절·단어 단위의 정확한 발화 시각을 보장하지 않는다.

## 4. 수정·일지 생성·확정

1. 잘못 인식된 전사와 영상 관찰을 원본에 맞게 수정한다.
2. 영상 근거를 검토하고 `장면 관찰 검토 완료`를 누른 뒤 `상담 일지 만들기`를 누른다.
3. 상담 목적·고민 / 보호자 보고 / 상담 중 관찰 / 훈련사 안내 / 합의한 과제 /
   후속 확인 / 중요 장면을 확인한다.
4. 각 항목이 음성 전사·수동 메모·AI 영상 관찰 중 어떤 출처인지 확인한다.
5. 전체 일지 검토 후 확정한다. JSON과 녹화를 내보내고 새로고침해 같은 기록을 다시 연다.

확인:

- “아직 과제는 정하지 않았다”는 발언으로 새로운 훈련 과제를 만들지 않는다.
- 영상에서 자세가 보였다는 이유로 불안·공격성·행동 원인을 확정하지 않는다.
- 근거 시간을 누르면 해당 녹화 위치를 볼 수 있다.
- 원문이나 관찰을 수정하면 기존 일지와 확정 상태를 다시 검토해야 한다.

## 5. 실패 처리 확인

- 카메라 권한 거부 후 허용: 원인을 알리고 다시 시도할 수 있어야 한다.
- 녹화 중 장치 분리: 정상 완료로 숨기지 않고 저장된 자료를 남겨야 한다.
- 영상 분석 취소: 원본·전사가 남고, 분석 완료나 일지 확정으로 표시되지 않아야 한다.
- 분석 중 페이지 새로고침: 서버 작업 상태를 다시 읽어야 한다.
- 녹화 삭제: 확인 창에서 취소하면 자료가 남아야 한다.

## 결과 기록 양식

| 녹화 시각/구간 | 실제 행동·발언 | 전사/영상 관찰 결과 | 차이·수정 내용 |
|---|---|---|---|
| 예: 00:30–00:40 | 물건을 왼쪽→오른쪽으로 옮김 | 직접 입력 | 직접 입력 |

정확도 평가는 실제 원본과 비교한다. 자동 시험 통과만으로 실제 반려동물 행동 인식이
오류 없다고 판단하지 않는다. 최초 시연은 2~3분으로 전체 흐름을 확인한 뒤 길이를 늘린다.
