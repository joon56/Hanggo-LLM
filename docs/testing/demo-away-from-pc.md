# PC를 집에 두고 다른 곳에서 시연하기

집의 이 PC가 서버와 AI(자막, 일지)를 맡는다. 시연 장소에서는 노트북(훈련사)과 휴대폰(보호자)으로 접속한다. 화면별 확인 항목 전체는 [사람 시연 대본](two-way-coaching.md)에 있다. 이 문서에는 장소를 옮길 때 필요한 것만 적는다.

## 1. 출발 전, 이 PC에서 (약 10분)

1. **절전을 끈다.** `설정 > 시스템 > 전원`에서 절전 모드로 바뀌는 시간을 `안 함`으로 바꾼다. 화면은 꺼져도 된다. 로그아웃하지 않는다.
2. **재시작을 막는다.** `설정 > Windows 업데이트`에서 업데이트를 일시 중지한다.
3. **GPU를 비운다.** SimulacraBench처럼 GPU를 쓰는 다른 작업을 끈다. 자막과 일지 모델이 GPU를 써야 한다.
4. **터널을 켠다.** 이 폴더에서 PowerShell을 열고 실행한다. 끝의 숫자는 터널을 열어 둘 시간이다. 지금부터 시연이 끝날 때까지 걸리는 시간에 2시간을 더해 넣는다.

   ```powershell
   npm.cmd run demo:tunnel -- 10
   ```

   `훈련사 주소: https://….trycloudflare.com/coaching`이 나오면 터널이 열린 것이다. **이 창은 닫지 않는다.** 닫으면 서버가 꺼진다.
5. **주소와 비밀번호를 챙긴다.**
   - 훈련사 주소를 카카오톡 `나와의 채팅` 같은 곳으로 휴대폰에 보낸다. 터널을 다시 켜면 주소가 바뀐다.
   - 접근 비밀번호는 `D:\hanggo\secrets.env`의 `APP_ACCESS_PASSWORD` 값이다. 단체방에 올리거나 영상에 찍히지 않게 한다.
6. **점검한다(1~2분).** 새 PowerShell 창에서 실행한다. 둘 다 통과하면 출발한다. 점검용 사례는 점검이 끝나면 지워진다.

   ```powershell
   npm.cmd run check:tunnel -- https://받은주소.trycloudflare.com
   npm.cmd run check:turn
   ```

7. **(권장) 원격으로 복구할 수단을 마련한다.** [Chrome 원격 데스크톱](https://remotedesktop.google.com/access)을 이 PC에 설치하고 PIN을 정해 둔다. 그러면 밖에서 터널이 닫혀도 노트북으로 다시 켤 수 있다. 이 수단이 없으면 터널이 닫힌 날에는 시연을 복구할 수 없다.

## 2. 시연 장소에서 (약 5분)

- **네트워크:** 노트북과 휴대폰을 가능하면 같은 Wi-Fi에 연결한다. 그러면 통화가 두 기기 사이에 직접 이어져 지연이 적다. 서로 다른 네트워크면 유럽 중계 서버를 거쳐 약 0.6초 늦어질 수 있다.
- **소리:** 두 기기가 같은 공간에 있으면 적어도 한쪽은 이어폰을 쓴다. 스피커 소리가 서로의 마이크로 들어가면 소리가 울리고 자막이 겹친다.
- **훈련사(노트북 Chrome):** 훈련사 주소를 열고 비밀번호를 넣은 뒤, 가상 이름으로 `상담 사례 만들기`를 누른다. 초대 QR이 나온다.
- **보호자(휴대폰):** 기본 카메라 앱으로 QR을 찍고 Chrome이나 Safari에서 열어 `상담 입장 준비`를 누른다. 카카오톡 안에서 열리면 화면 안내대로 다른 브라우저로 연다. 카메라와 마이크를 허용한다.

## 3. 10분 시연 흐름

| 순서 | 훈련사(노트북) | 보호자(휴대폰) | 보여 줄 것 |
|---|---|---|---|
| 1 | `상담 시작` 후 `입장` | `상담 입장` 후 `입장` | 서로의 영상과 소리 |
| 2 | `화면 공유`로 바탕화면 전체를 잠깐 공유했다가 끈다 | | 공유 화면이 크게 보인다 |
| 3 | `기록 동의` | `기록 동의` | `AI 기록 중`이 뜨고, 몇 초 뒤 자막이 나온다 |
| 4 | 아래 예시 대화 | 아래 예시 대화 | 말한 사람별 자막, 훈련사 화면의 체크 항목 |
| 5 | | 반려동물을 비추고 `캐치` | 훈련사 화면에 장면 표시가 뜬다 |
| 6 | `상담 종료` | | `정리 중`으로 바뀐다. 몇 분 걸린다 |
| 7 | `검토하기`를 누르고, 근거를 눌러 보고, 문장 하나를 고친 뒤 `확정하고 보호자에게 전달` | | 근거가 달린 일지 |
| 8 | | 새로고침 후 일지와 과제를 확인하고, 과제에 `했어요`를 누른다 | 보호자 화면에는 훈련사 메모가 보이지 않는다 |

**예시 대화**(가상):

- 보호자: "초코가 초인종 소리만 나면 계속 짖어요. 하루에 대여섯 번이고, 한 번 짖으면 2분쯤 가요."
- 훈련사: "짖을 때 보호자님은 어떻게 하세요?"
- 보호자: "안 된다고 소리치는데 더 짖어요."
- 훈련사: "이번 주에는 초인종 소리를 작게 틀고, 조용하면 간식을 주는 연습을 하루 세 번, 한 번에 5분씩 해 주세요. 목요일까지 해 보고 기록 남겨 주세요."
- 보호자: "네, 해 볼게요."

## 4. 막힐 때

| 증상 | 할 일 |
|---|---|
| 주소가 아예 안 열린다 | 집 PC가 꺼졌거나 절전에 들어갔거나, 인터넷이 끊겼거나, 터널 시간이 끝난 경우다. 원격 데스크톱이 있으면 터널을 다시 켜고 새 주소를 쓴다. 없으면 [실제 모델 시연 영상](https://joon56.github.io/Hanggo-LLM/demo/real/)으로 대신한다 |
| "링크가 잘렸습니다"가 나온다 | 링크 대신 QR을 다시 찍는다 |
| "연결 중"에서 넘어가지 않는다 | 두 기기를 같은 Wi-Fi로 맞추거나, 휴대폰을 데이터로 바꿔 본다 |
| 소리가 울리거나 자막이 겹친다 | 한쪽에 이어폰을 쓴다 |
| 자막이 나오지 않는다 | 양쪽 모두 `기록 동의`를 눌렀는지 본다. 처음 몇 초는 `받아쓰기 준비 중`이 보인다 |
| 일지가 오래 걸린다 | 일지 모델을 올리고 정리하는 데 몇 분 걸린다. 기다린다 |

## 5. 끝나면

- 집에 돌아와 터미널에서 Ctrl+C를 누른다. 정해 둔 시간이 지나도 자동으로 닫힌다. 터널이 열려 있는 동안에는 이 PC의 앱이 인터넷에 열려 있다.
- 절전 설정을 원래대로 돌린다.
- 시연에는 가상 이름만 쓴다. 영상에 비밀번호와 주소가 찍히지 않게 한다.
