# 상담 전 브리핑 시연

카메라 없이 보호자 기록과 확정 상담일지를 연결해 테스트한다. 실제 사용자 자료와 섞이지 않도록 별도 브라우저 프로필에서 진행한다.

## 준비

1. 프로젝트 폴더에서 `npm.cmd run dev:local` 실행.
2. 같은 브라우저 프로필에서 `http://127.0.0.1:5173/` 접속. 기록을 저장할 때와 브리핑을 볼 때 주소를 바꾸지 않는다.
3. 보호자 일상 기록에서 `시연초코`를 등록한다. 이미 등록했다면 기존 항목을 사용한다.

## 1. 보호자 기록 세 건 준비

아래 문장을 한 건씩 입력하고, 사건 카드의 반려동물·발생 시각·유형·지속 시간·상황·대응·반응을 원문과 대조한 뒤 저장한다. 날짜는 시연일 기준 실제 최근 날짜로 선택한다.

> 어제 오전 9시에 시연초코가 초인종 소리에 3분 짖었어요. 매트로 이동시킨 뒤 짖음이 줄었어요.

> 이틀 전 오전 9시에 시연초코가 초인종 소리에 5분 짖었어요. 매트로 이동시켰지만 계속 짖었어요.

> 사흘 전 오전 9시에 시연초코가 초인종 소리에 2분 짖었어요. 매트로 이동시킨 뒤 멈췄어요.

- AI 초안에서 상황·대응·반응이 빠졌으면 카드에서 원문에 맞게 수정한다.
- 기록을 세 번 저장한 것은 실제 짖음이 총 세 번뿐이었다는 뜻이 아니다.
- 직전 14일 기록이 없다면 기간 비교를 확정하지 않는 것이 정상이다.

## 2. 텍스트 상담일지 확정

상담일지의 텍스트 입력을 사용한다. 반려동물 이름은 `시연초코`, 훈련사 이름은 `시연 훈련사`로 입력한다.

> 보호자는 초인종 소리에 짖는 상황을 상담하고 싶다고 말했습니다.
> 이번 주 과제는 초인종 소리와 대응 뒤 반응을 기록하기로 했습니다.
> 다음 상담에서 매트로 이동한 뒤 반응이 달랐던 상황을 확인하기로 했습니다.

초안의 분류와 원문을 확인하고 확정·저장한다. 카메라로 작성했던 상세 상담일지가 이미 확정돼 있다면 그 자료도 브리핑에서 선택할 수 있다.

## 3. 브리핑 확인

1. **상담 전 브리핑**에서 `시연초코`를 선택한다.
2. 방금 확정한 상담일지를 직접 선택한다. 선택하지 않은 상담일지가 자동으로 섞이지 않는지 확인한다.
3. 로컬 AI 처리 동의를 확인하고 브리핑을 생성한다.
4. 핵심 3줄을 읽는다: **핵심 상황 / 변화·주의점 / 이번 상담에서 확인할 일**.
5. 근거를 열어 날짜와 원문을 대조한다. 상세 상담일지라면 해당 상담의 근거 시간도 확인한다.
6. 확인 질문이 초인종·매트 이동·이후 반응 같은 실제 기록과 연결되는지 확인한다.
7. JSON으로 내보내 생성 방식·자료 범위·근거를 보관한다.

상세 근거는 보호자 기록 최대 24건, 상담 항목 최대 12건, 원문 최대 400자 발췌다. 상담은 과제·목적·후속 확인 항목을 우선 포함한다. 생략 표시가 있으면 원본 기록에서 전체 내용을 확인한다. JSON도 상세 원문은 같은 발췌 범위이며, 기간 수치는 전체 사건을 집계한 값이다.

### 합격 기준

- 원문에 없는 원인·진단·훈련법이나 과제 완료 여부를 단정하지 않는다.
- 선택한 반려동물과 상담일지만 사용한다.
- AI가 실패해도 코드로 정리한 결과임을 명확히 표시하고 원문 근거를 확인할 수 있다.
- 자료가 없는 항목은 자료 부족·미확인으로 표시한다.
- 안전 관련 기록이 있으면 일반 집계 속에 묻히지 않고 근거와 함께 표시한다.

## 4. 예외 확인

- **일지 미선택:** 보호자 기록만으로 생성되며, 이전 상담 내용은 만들지 않는다.
- **기록 부족:** 하루치 기록만 있으면 부족 표시가 나와야 한다. 기록 없는 날을 행동이 없던 날로 해석하면 실패다.
- **다른 반려동물:** 다른 동물로 바꾸면 선택한 상담과 이전 결과가 해제돼야 한다.
- **확정 후 수정:** 상세 상담일지의 받아쓰기나 항목을 수정했다면 다시 검토·확정하고 선택한다. 브리핑이 이전 확정본을 그대로 사용하면 실패다.
- **서버 연결 실패:** 상세 상담일지의 유효성을 확인할 수 없다면 재연결·재선택 안내를 따라야 한다. 오래된 상담 자료로 생성한 결과를 최신 결과처럼 보여주면 실패다.

## 시연 설명

“위쪽 3줄로 상담의 출발점을 잡고, 필요한 항목은 날짜와 원문까지 펼쳐 확인합니다. 기록에서 서로 달랐던 반응과 이전 상담에서 확인하기로 한 내용을 질문으로 이어줍니다. 기록이 없는 부분은 추정하지 않습니다.”

실제 훈련사의 유용성 평가는 별도로 필요하다. 자동 테스트 통과가 상담 판단의 정확도를 보장하지는 않는다.
