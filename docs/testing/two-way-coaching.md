# 쌍방향 화상 코칭 사람 시연 대본

자동 검증(`e2e/two-way*.spec.ts`)과 [자동 시연 영상](https://joon56.github.io/Hanggo-LLM/demo/)은 합성 영상과 소리로 진행한다. 실제 카메라, 실제 네트워크, 실제 사람의 목소리와 사용감은 이 대본으로만 확인할 수 있다. 약 30분 걸린다.

## 준비물

- 이 PC(훈련사 역할). 카메라가 없어도 된다.
- 휴대폰 1대(보호자 역할). 후면 카메라로 반려동물이나 주변을 비춘다.
- 가능하면 휴대폰은 Wi-Fi를 끄고 LTE로 접속한다. 서로 다른 네트워크를 시험하기 위해서다.
- 이어폰 또는 분리된 공간. 같은 공간에서 스피커로 들으면 서로의 소리가 마이크로 다시 들어간다.
- 가상 이름만 쓴다. 화면 공유에 보일 수 있다.

## 시작

```powershell
npm.cmd run demo:tunnel
```

1. 화면에 나온 `훈련사 주소`를 PC 브라우저로 연다.
2. 접근 비밀번호를 입력한다. 처음 실행이면 터미널에 표시되고 `D:\hanggo\secrets.env`에 저장된다.
3. 터널을 연 동안 이 PC의 앱이 인터넷에 열린다. 끝나면 터미널에서 Ctrl+C를 누른다. 기본 4시간 뒤 자동으로 닫힌다.

주소를 얻은 뒤 PC에서 먼저 자동 점검을 한 번 돌릴 수 있다.

```powershell
npm.cmd run check:tunnel -- https://받은주소.trycloudflare.com
npm.cmd run check:turn
```

| 16 | | `기록 동의` | 다시 자막이 나온다 | |
| 17 | | Wi-Fi와 LTE를 바꾸거나 잠시 비행기 모드를 켰다 끈다 | 양쪽에 재연결 안내가 나오고 돌아온다 | |
| 18 | | 브라우저를 새로고침하고 다시 입장한다 | 다시 연결되고 지난 자막이 돌아온다 | |
| 19 | `상담 종료` | | 양쪽이 첫 화면으로 돌아간다. 훈련사 쪽 상담이 `정리 중`으로 보인다 | |
| 20 | 정리 중에 몇 번째 부분을 쓰는지 표시되는지 본다. 몇 분 뒤 `검토 대기`가 되면 `검토하기` | 첫 화면에 일지가 아직 안 보인다 | 왼쪽 전사, 오른쪽 일지 초안이 나온다. 초안 문장의 근거를 눌러 발화가 강조되는지 본다 | |
| 21 | 받아쓰기가 틀린 문장을 `전사 수정`으로 고친다 | | 수정 표시가 붙고 원문은 그대로 있다 | |
| 22 | 장면 관찰이 사진과 맞는지 읽고 맞는 것만 체크한다 | | 사진에 없는 내용을 쓰지 않았는지 적는다 | |
| 23 | 일지 문장 하나를 고치고 과제의 담당·횟수·기한을 확인한다 | | 전사에 없던 내용이 들어갔는지 적는다 | |
| 24 | `확정하고 보호자에게 전달` | 새로고침 | 보호자에게 확정본과 과제가 보인다. 메모와 체벌 언급은 보이지 않고, 하지 말라는 안내는 보인다. `인쇄·PDF 저장`으로 일지만 저장된다 | |
| 25 | | 과제에 `했어요` 또는 `일부만 했어요`, 메모를 말이나 글로 남긴다 | 수행 기록이 쌓인다 | |
| 26 | | `일상 기록`을 쓰고 `내용 확인`, 날짜를 고른 뒤 `저장` | 이해한 내용을 먼저 보여 준다 | |
| 27 | `브리핑`을 열고 `상담 시작`으로 다음 상담에 들어간다 | | 지난 과제, 수행 기록, 일상 기록이 근거와 함께 나온다. 보호자 화면에는 안 보인다 | |

## 결과 기록

- 시연 날짜, 기기, 브라우저, 네트워크 조합:
- 연결까지 걸린 시간:
- `중계 연결` 표시 여부:
- 소리·영상 품질 체감:
- 자막까지 걸린 시간과 받아쓰기 정확도 체감(실제 사람 음성):
- 초안에서 고친 문장 수와 고친 이유:
- 사실과 다른 문장, 전사에 없는 내용:
- 실패한 순서와 그때 화면 문구:

휴대폰 화면 공유는 브라우저가 지원하지 않으면 버튼이 나오지 않는다. 지원 여부를 함께 적는다.
