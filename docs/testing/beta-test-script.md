# 행고 로컬 베타 시연 대본 · 15분

회의 진행자가 자기 PC의 **로컬 앱**을 화면 공유하며 기능을 확인하는 절차입니다. 예상 시간은 모델 준비가 끝난 뒤의 목표치입니다. 첫 모델 로딩이나 PC 상태에 따라 늘어날 수 있습니다. 체크 결과는 [beta-results.csv](beta-results.csv)에 같은 단계 ID로 기록합니다.

## 공유 전 준비 · 10분 이상 여유

1. 가상 이름 **초코**, **시연 훈련사**, **콩이**, **시연 직원**만 사용합니다. 화면 공유와 녹화에는 입력 내용이 보일 수 있습니다. 기존 실제 기록이 보이는 브라우저 프로필은 쓰지 않습니다.
2. 시연용 별도 일반 브라우저 프로필을 열고 시크릿 모드는 피합니다. 상담일지·보호자 기록·브리핑은 같은 프로필과 같은 `http://127.0.0.1:5173/` 주소에서 사용합니다. `localhost`와 `127.0.0.1`을 섞거나 포트를 바꾸면 저장소가 달라집니다. 기존 브라우저 자료를 일괄 삭제하지 않습니다.
3. 터미널에서 `npm.cmd run local:check`, `npm.cmd run dev:local`을 확인합니다. 별도 터미널에서 `npm.cmd run beta:check`, 필요하면 `npm.cmd run beta:check -- --warmup`을 실행합니다. 웜업은 가상 HTTP 요청 1회로 일일 요청 한도 1회를 사용하며 시연 기록을 미리 저장하지 않습니다.
4. 브라우저에서 `http://127.0.0.1:5173/`을 열고 연결 패널에 로컬 텍스트·음성 준비 상태가 보이는지 확인합니다. 브라우저의 마이크 권한을 허용하고 짧은 시험 녹음을 재생해 봅니다. 시작 전 시험 녹음은 화면에서 삭제합니다.
5. 공유 대상은 앱 탭 또는 앱 창으로 제한합니다. 설치 터미널과 기존 기록·다른 창을 공유하지 않습니다. 발표 대본과 아래 입력 문장은 발표자만 보이는 곳에 둡니다.

**준비 판정 P00:** 로컬 주소가 열리고 텍스트·음성 준비 상태가 정상이며 마이크가 녹음됩니다. 하나라도 실패하면 원인을 기록하고 [대체 경로](#대체-경로)로 진행합니다. 공개 GitHub Pages에서는 AI 생성·받아쓰기를 시연할 수 없습니다.

## 15분 진행

### 0:00–3:30 · 상담일지 텍스트

**N01** 상단 **상담일지**를 엽니다. **반려동물 이름**에 `초코`, **상담 날짜**에 오늘 날짜, **훈련사 이름**에 `시연 훈련사`를 입력합니다. **직접 입력하기** → **상담 요약 원문**에 아래 문장을 붙여 넣습니다.

> 오늘 1.5미터 거리를 두고 기다리는 모습을 관찰했습니다.

“짧은 사후 요약을 입력합니다. 숫자와 관찰 근거가 원문에서 유지되는지 보겠습니다.”

**N02** **음성·텍스트를 이 PC의 로컬 AI 서버에서 처리하는 데 동의합니다.** 확인란 → **일지 초안 만들기**. **상담일지 초안**의 관찰 항목과 **원문 근거**를 열어 `1.5미터`와 실제 문장 일치를 확인합니다. 생성 완료 시간과 `로컬 AI 초안` 또는 수동 검토 표시를 기록합니다. 다른 수치·행동이 생기면 FAIL입니다.

**N03** **원문과 일지를 확인했으며, 이 브라우저에 저장합니다.** 확인란 → **승인하고 저장**. 저장 알림 확인 → 페이지 새로고침 → 왼쪽 **저장한 기록**에서 초코 기록 열기. “승인한 내용은 이 브라우저에 저장되며 다시 열 수 있습니다.” **JSON 다운로드**로 파일을 내려받아 원문과 근거 필드가 있는지 확인합니다. 다른 기록은 건드리지 않습니다.

### 3:30–6:30 · 상담일지 음성

**V01** **새 상담 기록**을 눌러 동일한 가상 이름·오늘 날짜를 입력합니다. **음성으로 남기기** → 마이크 **녹음 시작**을 누르고 자연스럽게 말합니다. 말끝까지 포함해 **3초 이상**, 60초 이내에 **녹음 정지**를 누릅니다.

> 오늘 초코가 앉아를 세 번 연습했습니다.

**V02** **상담 요약 녹음 재생**에서 소리를 확인합니다. 로컬 처리 확인란 → **음성 받아쓰기**. **받아쓰기 · 직접 입력**에서 초코·앉아·세 번(또는 3번)을 비교합니다. 잘못 인식되면 화면에서 원문을 고치고 수정 사실을 결과에 적습니다. **받아쓰기 내용을 듣고 확인했습니다.** 확인란 → **일지 초안 만들기**. “받아쓰기는 사람이 확인한 뒤 일지로 넘깁니다.” 녹음·받아쓰기·초안 소요 시간을 각각 기록합니다. 이 음성 문장은 이전 환경에서 3.75초 녹음, 약 9초 받아쓰기 결과가 있었지만 오늘 속도를 보장하지 않습니다.

### 6:30–9:30 · 보호자 일상 기록과 브리핑

**O01** 상단 **보호자 일상 기록** → **반려동물 등록**의 **이름**에 `초코`, **별명 · 쉼표로 구분**에 `코코` → **등록**. **오늘의 관찰**에서 **텍스트** 선택, **원문 또는 받아쓰기**에 붙여 넣습니다.

> 초코 산책 30분

**O02** 로컬 처리 확인란 → **AI 사건 초안 만들기**. **사건 확인**에서 **원문 근거**, **반려동물**, **유형**, **발생 시각**, **지속 시간 · 분**을 확인합니다. 시각은 원문에 없으므로 임의로 채우지 않습니다. 30분이 유지되고 원문에 없는 사실이 없으면 통과입니다. **원문과 사건 내용을 확인했습니다.** → **검토 후 저장** → **저장한 일상 기록**의 **열기**로 재열람합니다.

**B01** 상단 **상담 전 브리핑** → **반려동물**에서 초코 선택. **사용 자료**의 보호자 기록 수와 **자료 범위**의 기록된 날 수를 읽습니다. 로컬 처리 확인란 → **AI 브리핑 만들기**. **사실과 근거**에서 **근거 보기**를 눌러 `초코 산책 30분` 원문을 확인합니다. “저장된 기록이 하루뿐이므로 14일 추세를 말할 자료가 부족합니다.” 부족 표시나 변화 생략이 맞는 결과입니다. 숫자·개선 추세를 만들어 내면 FAIL입니다. 직전 상담은 같은 이름의 승인 일지가 검색되므로 실제 표시된 기록만 설명합니다.

### 9:30–12:30 · 보호소 프로필

**S01** 상단 **보호소 프로필** → 화면 제목 **입양 프로필**. **동물 이름** `콩이`, **종** `개`, **나이 · 개월, 모르면 빈칸**은 비워 둡니다. **관찰 메모**의 **날짜**는 오늘, **작성자 역할**은 **직원**, **관찰 내용**에는 다음 문장을 붙여 넣습니다.

> 사람에게 다가왔습니다. 다른 개를 보면 짖음.

**S02** 로컬 처리 확인란 → **AI 프로필 초안 만들기**. **사회성**과 **함께 안내할 주의 사항**을 읽고, 각 관찰의 **메모 근거**를 엽니다. 사람에 대한 긍정 관찰과 다른 개에 대한 주의 관찰이 함께 남고, 고양이 등 관찰하지 않은 대상은 미확인이어야 통과입니다. 주의 문구 삭제·근거 없는 성격 단정은 FAIL입니다. **확정 직원 이름**에 `시연 직원` → **메모와 모든 관찰·주의 사항을 확인했습니다.** → **프로필 확정·저장**. **저장한 프로필**에서 **열기**로 다시 확인합니다. 레슨 후보가 없으면 실제 카탈로그 미연결 상태로 설명합니다.

### 12:30–15:00 · 증거, 삭제 확인, 마무리

**D01** 보호소의 시연용 콩이 프로필에서 **JSON 내보내기**가 보이면 저장합니다. **저장한 프로필**의 콩이 행에서 **삭제** → 브라우저 확인창 **취소**. 콩이가 남아야 합니다. 다시 같은 콩이 행의 **삭제** → 확인. 콩이만 목록에서 사라져야 합니다. 초코나 기존 자료는 삭제하지 않습니다.

**E01** 결과 CSV에 각 단계의 PASS/FAIL, 실제 결과, 지연 시간, 문제를 적습니다. 실패 시 화면의 **이상해요**로 요청 ID·원문·출력 JSON을 내려받을 수 있습니다. 내려받은 파일에는 가상 자료만 넣습니다. “오늘은 네 기능의 입력, 근거 검토, 브라우저 저장을 확인했습니다. 결과는 기록한 항목만 말씀드립니다.”

## 선택 점검 · 15분 뒤 2분

**O03** 보호자 음성 흐름도 확인하려면 **보호자 일상 기록**의 **새 기록** → **음성** → **새로 녹음**. `초코 산책 30분`을 3초 이상 또렷하게 말하고 **녹음 중지** → **녹음 재생** → 로컬 처리 확인란 → **받아쓰기**. **원문 또는 받아쓰기**에서 이름과 30분을 확인·수정하고 **받아쓰기를 듣고 원문을 확인했습니다.** → **AI 사건 초안 만들기**. 사건 근거와 30분을 확인하되 **중복 저장하지 않습니다**. 음성 인식 결과와 소요 시간을 O02와 별도로 기록합니다.

## 대체 경로

- **로컬 서버 또는 모델 준비 실패:** 앱 연결 패널·`beta:check` 결과를 기록합니다. AI 버튼이 수동 모드로 바뀌면 **수동 검토 초안 만들기** 또는 **기록으로 브리핑 만들기**를 보여 주고 수동 결과로 표시합니다. AI 성공으로 말하지 않습니다.
- **마이크 권한 거부·무음·받아쓰기 실패:** 권한과 입력 장치를 확인합니다. 녹음을 다시 재생해 실패를 기록한 뒤 **직접 입력하기** 또는 보호자 기록의 **텍스트**로 전환합니다. V02는 FAIL 또는 미실행으로 남깁니다.
- **모델 지연:** 30~60초 뒤에도 진행 중이면 상태를 설명하고 기다릴지 다음 기능으로 이동할지 결정합니다. 임의 결과를 보여 주지 않습니다. 취소 시 이미 시작한 로컬 처리가 잠시 계속될 수 있습니다.
- **초안 오류:** 원문·근거·숫자 오류를 결과에 남기고 해당 초안을 승인하지 않습니다. 수동 수정이 가능하면 수정 뒤 별도 확인합니다.
- **기록이 브리핑에서 안 보임:** 같은 브라우저 프로필, 같은 `127.0.0.1:5173`, 저장 성공 알림, 초코 이름을 확인합니다. 저장된 자료가 적으면 추세를 보여 주지 않습니다.

## 5분 짧은 경로

공유 전 P00 완료를 전제로 합니다. **N01–N02**(1분 30초) → **O01–O02**(1분) → **B01**(1분) → **S01–S02**(1분 30초). 시간이 부족하면 저장·음성·삭제 단계는 “미실행”으로 기록합니다. 짧은 경로에서도 14일 추세나 레슨을 꾸며 보여 주지 않습니다.
