# 실시간 상담 시연 대본

이 문서는 기존 **탭 공유** 시연이다. 실제 카메라·마이크 녹화와 종료 후 영상 분석은
[카메라 상담 시연 대본](camera-consultation.md)을 사용한다. 기본 입력이 카메라이므로
아래 탭 시연에서는 먼저 녹화 입력을 탭 공유로 바꾼다.

## 준비

Windows Chrome/Edge에서 **브라우저 탭**을 공유한다. 탭에서 동영상 또는 웹 화상 상담을
실행한다. 노트북 스피커 소리가 마이크로 다시 들어가는 것을 줄이려면 이어폰을 사용한다.
이번 시연은 최대 60분이며, 화면 AI 분석은 포함하지 않는다. 중요 장면은 직접 표시한다.

1. Ollama를 실행한다. 텍스트 모델은 기존 `qwen3.5:9b`를 사용한다.
2. GPU 음성 후보를 설치한다. 이 PC에서는 설치·SHA-256 검증을 마쳤다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-speech-candidates.ps1
   ```

3. 로컬 `.env`에서 다음 값을 확인한다.

   ```dotenv
   AI_ENABLED=true
   FEATURE_LIVE_CONSULTATION_ENABLED=true
   LIVE_SPEECH_MODEL=whisper-turbo
   CONSULTATION_DIRECTORY=.local-data/consultations
   ```

4. `npm.cmd run dev:local`을 실행하고 `http://127.0.0.1:5173/`에 접속한다.
   GitHub Pages 체험판에서는 이 로컬 상담 기능을 실행하지 않는다.

## 10분 시연

### 1. 상담 준비

상담 화면에서 가상 이름 `초코`, 훈련사 `시연자`, 오늘 날짜를 입력한다.
녹화와 로컬 AI 처리 동의를 확인한다. 내 목소리도 기록하려면 마이크를 켠다.

**확인:** 음성 모델 표시가 `whisper-turbo`이고 준비 상태를 확인할 수 있다.

### 2. 탭 공유 시작

상담 시작 버튼을 누르고, 동영상이나 웹 상담이 실행되는 **브라우저 탭**을 선택한다.
브라우저 공유 창의 **탭 오디오 공유**를 켠다.

**확인:** 공유 화면 미리보기와 경과 시간이 나타난다. 오디오 없는 화면·창 공유를 선택하면
상대 소리가 기록되지 않는다는 안내를 받고 다시 선택할 수 있다.

### 3. 내 목소리로 인식 확인

마이크를 켠 상태에서 아래 문장을 자연스럽게 읽는다. 각 문장 뒤 잠시 쉰다.

> 오늘 초코는 산책 중 다른 개를 보고 세 번 짖었습니다. 줄을 당기지는 않았습니다.
>
> 과제는 아직 정하지 않았습니다. 간식을 주지 말라는 뜻은 아닙니다.
>
> 훈련사가 관찰했을 때 보리는 현관 소리가 나자 문 쪽으로 이동했습니다.

**확인:** 약 10초 분량을 모아 전사하므로 말하는 즉시 모든 글자가 나오지는 않는다.
`초코`, `짖었습니다`, `않았습니다`, `나자`를 확인한다. 숫자 `세 번 → 3번`은 같은 의미의 표기 변환이다.
내 음성과 공유한 탭의 상대 음성이 모두 기록되는지 따로 확인한다.
구간 경계에서 문장 끝이 중복되거나 조각날 수 있다. 해당 시간의 녹화를 듣고 전사를 수정한다.

### 4. 중요 장면 표시

동영상의 특정 행동이 보일 때 중요 장면을 표시하고 다음 메모를 남긴다.

> 현관 소리에 문 쪽으로 이동한 장면. 이름을 부른 뒤 반응 확인.

**확인:** 상담 시작 기준 시간이 저장된다. 이 메모는 사람이 입력한 관찰로 표시된다.
AI가 영상을 해석했다고 표시하지 않는다.

### 5. 종료와 녹화 확인

상담을 종료한다. 남은 저장·전사가 끝날 때까지 기다린다.

**확인:** 녹화를 재생하면 화면과 소리가 나온다. 중요 장면 또는 전사 시간을 누르면
해당 위치로 이동한다. 미처리·실패 구간이 있으면 완료로 보이지 않는다.

### 6. 전사 수정과 상세 일지

잘못 인식된 글자가 있으면 전사에서 수정한 뒤 일지를 생성한다.
상담 목적·고민, 보호자 보고, 상담 중 관찰, 훈련사 안내, 합의한 과제,
후속 확인, 중요 장면의 7개 항목을 검토한다.

**확인:** 항목마다 인용문·시간 근거가 있다. `과제는 아직 정하지 않았습니다`가
새로운 훈련 과제로 바뀌지 않는다. 분류가 없는 항목을 임의 내용으로 채우지 않는다.
AI 분류에서 빠져 원문 그대로 보존된 항목에는 검토 표시가 있다.

### 7. 승인·복구·내보내기·삭제

검토 후 승인하고 새로고침해 같은 상담을 다시 연다. 전체 전사·일지 JSON과 녹화 파일을
내보낸다. 마지막에 테스트 상담을 삭제한다.

**확인:** 재접속 후에도 상담이 남는다. 삭제 확인에서 취소하면 유지되고,
확인하면 해당 상담의 저장 자료가 삭제된다.

## 실패 상황도 한 번씩 확인

- 공유 선택 취소: 시작 전 상태로 돌아오며 마이크·화면 공유가 남지 않는다.
- 브라우저의 공유 중지 버튼: 녹화를 마무리하고 저장한 부분을 확인한다.
- 마이크 끄기: 탭 음성만 기록한다. 마이크 사용 여부가 화면과 일치한다.
- 처리 지연·업로드 실패: 대기·실패 상태를 보여주고 무한히 메모리에 쌓지 않는다.
- 상담 중 페이지 닫기·서버 종료: 재실행 시 중단된 상담으로 보이고, 저장된 부분을 확인한다.
- 60분 도달: 자동 종료 후 남은 파일을 저장한다. 서버는 마지막 업로드를 위한 짧은 유예 시간을 둔다.

## 결과 기록

실제 발언, 인식 결과, 탭 오디오/마이크 설정, 전사 지연, 실패 구간을 함께 기록한다.
실제 목소리의 정확도는 [모델 비교 절차](../llm/speech-comparison.md)로 다시 비교할 수 있다.

원본 녹화·전사·일지는 기본적으로 이 PC의 `.local-data/consultations`에 저장된다.
자동 백업이나 팀 공유 저장은 없다. `.local-ai`, `.local-data`, `.tmp`, `test-audio`는 Git에서 제외한다.
