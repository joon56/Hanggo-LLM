# 외부 API 텍스트 모델 연결과 모델 선택 — 1차 설계

사용자 승인: 2026-11-11. 런칭 전까지 로컬과 외부 API를 함께 지원하고, 런칭 후 외부 API로 정착하는 방향이다.

## 목적

텍스트 기능 4개(상담일지, 보호자 일상 기록, 상담 전 브리핑, 보호소 프로필)를 외부 API로도 실행할 수 있게 한다. 같은 코드 경로로 후보 모델을 기존 평가 자료에서 비교해 최종 모델을 근거로 고른다.

후보는 Gemini 3.8 Flash(`gemini-3.8-flash`), Claude Sonnet 5.5(`claude-sonnet-5-5`), Claude Haiku 5.5(`claude-haiku-5-5`)이다. 기준선은 로컬 `qwen3.5:9b`의 이전 측정 74/82다.

## 범위

포함: 로컬/API 선택 설정, Gemini·Claude 연결, 문장 번호 변환, API 서비스 조립, 오류 처리, 모델 비교 평가 도구와 실제 평가, 화면 동의 문구와 점검 도구.

제외: 음성 전사와 영상 관찰의 API 전환(2차), 실제 행고 앱(Firebase) 이식, GitHub push, 실제 보호자·상담 자료의 API 전송.

## 설정

```dotenv
AI_PROVIDER=local                 # local | api
API_TEXT_MODEL=gemini-3.8-flash   # 상담일지·브리핑·보호소
API_SHORT_MODEL=claude-haiku-5-5  # 보호자 기록
GEMINI_API_KEY=
ANTHROPIC_API_KEY=
```

업체는 모델 이름의 접두사(`gemini-`, `claude-`)로 정한다. 1차에서 음성 전사와 영상 관찰은 `AI_PROVIDER`와 관계없이 로컬로 남는다. 로컬과 API 사이의 자동 전환은 두지 않는다. 키는 서버 `.env`에만 두고 `VITE_` 접두사를 쓰지 않는다.

## 구조

1. **업체 연결 (Gemini, Claude):** 지시문, 고정 출력 형식, 입력을 보내고 JSON, 사용 토큰, 처리 시간을 돌려받는다. 각 업체 공식 SDK를 쓴다.
2. **번호 변환:** 원문을 번호 붙은 단위로 나누고, 모델이 고른 번호를 원문 그대로의 인용으로 되돌린다. 네트워크를 쓰지 않는 순수 함수로 둔다.
3. **API 서비스 조립:** `server/ollama.ts`의 로컬 조립과 같은 모양으로 기존 `createNoteService`, `createOwnerService`, `createBriefService`, `createShelterService`를 재사용한다. 서비스의 검증과 대체 경로는 바꾸지 않는다.
4. **설정·선택:** `server/config.ts`가 설정을 검사하고 `server/providers.ts`가 로컬 또는 API 조립을 고른다. 로컬 주소만 허용하는 Ollama 검사는 로컬 경로에만 적용한다.

## 문장 번호 방식

모델은 원문을 다시 쓰지 않고 번호만 고른다. 코드는 원문에서 해당 부분을 그대로 잘라 `sourceQuote`에 넣고 기존 서비스 검증에 넘긴다. 출력 형식은 요청마다 바뀌지 않는다. 그래서 Claude의 형식 처리 캐시를 재사용하고 Gemini의 형식 복잡도 제한을 피한다.

- **상담일지:** `splitNoteSentences`로 나눈 문장에 번호를 붙인다. 2,000자를 넘는 문장은 공백 기준으로 나눈다. 모델은 문장 번호와 분류를 고른다. 중복과 원문 일치는 기존 검증이 확인한다.
- **보호자 기록:** 문장 번호의 시작과 끝을 고른다. 인용은 시작 문장의 첫 글자부터 끝 문장의 마지막 글자까지 원문에서 잘라낸다. 시각, 지속 시간, 대응 같은 다른 필드는 모델이 쓰고 기존 근거 검증을 거친다.
- **보호소 프로필:** 메모 문장을 수동 초안(`createManualShelterDraft`)과 같은 방식으로 나눠 메모별 번호를 붙인다. 모델은 번호, 분류, 긍정·주의를 고른다. 코드가 `memoId`와 인용을 채운다.
- **브리핑:** 이미 fact ID를 고르는 구조다. 요청마다 바뀌는 열거형 대신 문자열 ID로 받고, 기존 검증이 ID를 확인한다.

## 오류 처리

`AI_PROVIDER=api`에서 필요한 키가 없거나 모델 접두사를 알 수 없으면 서버 시작 시 이유와 함께 실패한다.

시간 초과, 429, 5xx, Claude의 `refusal`, 출력 잘림(`max_tokens`), Gemini의 형식 거절(400)은 호출 실패로 처리한다. SDK 재시도 1회 뒤 기존 서비스의 시도와 수동 검토 초안 대체로 이어지며, 이 경우 AI 성공으로 기록하지 않는다. 기존 `AI_DAILY_LIMIT`을 그대로 적용한다. 로그에는 원문을 남기지 않고 모델, 토큰 수, 처리 시간만 남긴다.

## 개인정보와 화면

기존 개인정보 가림을 거친 텍스트만 보낸다. 1차 기간에는 가상 자료만 API로 보낸다는 점을 README와 `.env.example`에 적는다. Gemini는 유료 등급 키만 쓴다. 무료 등급 입력은 Google 제품 개선에 쓰이며, 이는 코드로 확인할 수 없어 설정 안내에 적는다.

동의 문구는 설정에 따라 달라진다. 로컬은 "로컬 AI 처리", API는 "외부 AI(Google·Anthropic)로 전송해 처리"다. 실시간 상담 화면도 포함한다. 상담 종료 후 일지 생성에 전사 텍스트가 텍스트 모델로 가기 때문이다. 연결 상태 화면은 현재 방식과 모델 이름을 보여준다. `local:check`와 `beta:check`는 API 방식에서 키 존재만 확인하고 비용이 드는 호출은 하지 않는다. `scripts/configure-local.mjs`가 `AI_PROVIDER`를 지우지 않게 고친다. 공개 체험판 빌드는 바뀌지 않는다.

## 모델 선택 검증

`npm.cmd run llm:eval:api -- --model <모델 ID> [--all]`로 기존 로컬 평가와 같은 사례와 합격 조건을 실행한다. 기본은 로컬 평가와 같은 16개, `--all`은 82개(상담일지 30, 보호자·브리핑·보호소 52)다.

사례별 합격 여부와 실패 이유, 처리 시간, 입력·출력 토큰, 비용을 기록한다. 비용은 2026-11 공식 가격표 기준 상수로 계산하고 날짜를 함께 남긴다(Gemini 3.8 Flash $0.75/$3.75, 2027-01부터 $1.50/$7.50. Claude Sonnet 5.5 $2/$10. Claude Haiku 5.5 $0.10/$0.50, 100만 토큰당 입력/출력). 82개 사례가 짧은 입력 위주이므로 가상 60분 분량 전사 1건의 처리 시간과 비용을 따로 잰다.

추론 강도는 낮게 시작한다. 합격률이 기준선 74/82보다 낮으면 한 단계 올려 다시 잰다.

결정 규칙은 다음 순서다.

1. 합격률이 가장 높은 모델
2. 차이가 2건 이하면 더 싼 모델
3. 처리 시간이 2배 이상 차이 나면 함께 보고

기능별로 다른 모델을 고를 수 있다.

실제 평가 비용은 3개 모델 전체와 재측정을 합쳐 약 $2 이하로 추정한다. 비용이 드는 실행이므로 실행 전에 사용자 확인을 받는다. 결과는 `docs/llm/api-comparison.md`에 기록하고 README를 갱신한다.

## 테스트

번호 변환은 단위 테스트로 확인한다(번호 부여, 원문 복원, 긴 문장 분할, 범위 밖·중복 번호). 업체 연결은 가짜 SDK 응답으로 테스트하고 네트워크를 쓰지 않는다. 설정 검사, 로컬/API 선택, 동의 문구를 테스트한다. 기존 단위 테스트 450개와 브라우저 테스트 16개가 계속 통과해야 한다.

## 작업 순서

1. 연결 구조와 오류 처리
2. 평가 도구
3. 실제 평가 (키 필요, 실행 전 비용 확인)
4. 모델 확정
5. 화면, 동의 문구, 점검 도구

작업은 `feat/api-providers` 브랜치에서 한다.

## 계획 단계에서 확인할 것

- Gemini 공식 SDK의 구조화 출력 지원 방식과 요청 형식. 공식 문서 예시는 `POST /v1beta/interactions`의 `response_format`이다.
- Gemini의 추론 강도 설정 이름과 단계.
- Claude는 `output_config.format`으로 JSON 형식을 강제하고, 모든 객체에 `additionalProperties: false`를 둔다. 2026-10-21 API 버전에서 거절되는 `temperature`는 보내지 않는다.
