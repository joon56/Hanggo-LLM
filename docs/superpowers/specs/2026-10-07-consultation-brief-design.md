# 상담 전 브리핑 개선 설계

사용자 승인: 2026-10-07. 추천 방향으로 구현 요청.

## 목적

짧은 요약과 자세한 상담 준비 자료를 한 화면에서 제공한다. 기본 화면은 핵심 3줄이며, 훈련사는 필요한 근거와 확인 질문을 이어서 읽는다.

## 자료와 출력

- 최근 14일 보호자 기록, 그 직전 14일 비교 자료.
- 사용자가 직접 선택한 확정 상담일지 1건. 기존 텍스트·요약 음성 일지와 새 상세 상담일지 모두 연결한다.
- 핵심 3줄: 핵심 상황 / 변화·주의점 / 이번 상담에서 확인할 일.
- 상세 근거: 날짜, 자료 종류, 원문, 상세 상담의 근거 시간.
- 확인 질문 최대 3개: 기록된 상황·보호자 대응·이후 반응·이전 과제의 미확인 내용을 구체적으로 짚는다.
- 기존 수치 사실표와 JSON 내보내기를 유지한다.

## 생성 방식

수치와 근거 연결은 코드가 만든다. 로컬 Ollama는 검증 가능한 근거의 선택·우선순위에 사용한다. 기록에 없는 문장·숫자·원인·진단·훈련법을 추가하지 않는다. 과제의 수행 여부는 기록이 없으면 미확인이다.

자료가 적어도 3개 역할은 유지하고 부족한 부분을 명시한다. 긴 상담은 전사 전체를 다시 전송하지 않고 상담 항목 중 제한된 근거를 사용하며 생략 범위를 표시한다.

## 상태와 실패

상담은 이름만으로 자동 선택하지 않는다. 상세 상담일지는 서버가 현재 확정 상태, 반려동물 이름, revision을 검증한다. 자료를 바꾸면 이전 생성 결과를 무효화하고 늦은 응답을 무시한다. 연결된 일지가 수정·삭제·미확정 상태가 되면 다시 선택하도록 안내한다.

모델 실패는 코드 기반 결과로 대체할 수 있다. 선택 상담의 유효성 확인 실패는 모델 실패와 구분한다. 서로 다른 반려동물의 기록, 미래 사건, 시각 불명확 기록, 출처가 불명확한 안전 신호를 선택 동물의 현재 사실로 섞지 않는다.

## 검증

단위 테스트, 실제 저장소를 쓰는 API 검증, 화면 동작 테스트, 타입 검사·빌드, 기존 fixture 평가를 수행한다. 한국어 합성 기록으로 실제 로컬 모델과 Chrome 흐름을 확인하고 모델 성공·대체 결과·실행 시간을 구분해 기록한다.

## 범위 밖

카메라 복구, 새 영상 분석, 원격 화상 통화, 레슨 카탈로그, 입양 프로필, 외부 유료 API, 모델 교체. 기존 사용자 저장 자료는 수정하지 않는다.
