# 로컬 카메라 상담 녹화·영상 분석

2026-10-07 사용자가 확정한 흐름: 카메라로 행동과 상담을 함께 녹화·전사 → 종료 후 영상 분석·일지 작성.

## 범위

- Windows Chrome/Edge, 현재 PC 카메라·마이크, 최대 60분. 원격 통화는 보류한다.
- 녹화 중 Whisper large-v3-turbo GPU 전사를 사용한다. 녹화 종료와 잔여 전사 완료 후
  음성 모델을 해제하고 설치된 qwen3.5:9b로 장면을 분석한다. 두 모델을 동시에 올리지 않는다.
- 기존 탭 녹화도 선택 가능하게 유지한다. 새 기본 입력은 카메라다.
- 영상 분석은 녹화에서 추출한 시간별 장면을 대상으로 한다. 정밀 행동 탐지기나 전체 프레임
  분석으로 표시하지 않는다. 짧은 행동 누락·오인식 가능성을 원본 검토로 확인한다.

## 기록과 근거

- 영상·음성은 같은 녹화 시작 기준 시간을 사용한다. 녹화 준비 시간은 포함하지 않는다.
- 기본 30초 간격 장면과 수동 중요 메모 시점을 분석한다. 각 시점 전후 약 1초의 최대 3개
  프레임을 함께 사용한다. 분석 범위·진행률·실패를 표시한다. 최대 240개 장면이며 초과 시
  조용히 버리지 않고 분석 대상이 너무 많다고 알린다.
- 프레임 시각은 관찰 근거 시각이다. 행동 시작·종료나 보상 반응 지연을 임의로 추정하지 않는다.
- AI는 영상에서 보이는 자세·위치·상호작용을 짧게 기록한다. 보이지 않는 심리·진단·원인,
  발언하지 않은 훈련 지시를 만들지 않는다. 관찰할 정보가 없으면 빈 결과를 허용한다.
- 영상 관찰에는 실제 분석 프레임과 녹화 재생 링크를 붙인다. 발언 인용·수동 메모·AI 영상
  관찰의 출처를 구분한다. 관찰을 수정하면 최초 모델 결과도 보존한다.
- 기존 7개 일지 항목과 근거 검증을 유지한다. 영상 관찰은 관찰 항목의 별도 근거가 된다.
- 카메라 기록은 영상 분석을 완료해야 일지를 생성할 수 있다. 확정에는 영상 관찰 검토와
  기존 전체 일지 검토가 필요하다. 영상 분석 실패·취소 시 성공으로 표시하지 않는다.
- 분석 재실행·관찰 수정·원문 변경 후에는 이전 일지 검토 상태를 재사용하지 않는다.

## 화면

1. 카메라/탭 입력 선택, 상담 정보와 처리 동의, 녹화 시작.
2. 실제 영상 미리보기, 음량, 전사, 중요 순간 메모, 종료·저장.
3. 영상 분석 시작, 진행률·실패·취소·재시도, 장면별 썸네일·관찰 수정·전체 영상 근거 검토.
4. 상담일지 생성, 근거 장면/전사 이동, 수정·검토·확정, 녹화와 JSON 내보내기.

## 실행과 보존

- 분석 작업은 서버에서 순서대로 처리하고 상태를 저장한다. 페이지를 다시 열어 확인할 수 있다.
- 인증·Origin·입력 크기·세션 경로 검증을 기존 API와 동일하게 적용한다.
- ffmpeg 프로세스와 Ollama 요청에 시간·출력 한도와 취소를 적용한다. 프레임은 사용자 PC에만 저장한다.
- 종료·삭제 시 분석 작업을 취소하고 GPU 예약을 반환한다. 서버 재시작 후 처리 중 작업은 실패로 표시한다.
- 녹화 원본과 전사는 영상 분석 실패 후에도 보존한다. 실패한 분석 때문에 녹화 자체를 손상시키지 않는다.

## 검증

- 카메라 권한 요청에 video/audio가 모두 포함되고 화면 공유 선택창 없이 시작되는지 검증.
- 권한 거부, 장치 단절, 최종 청크 저장, 기존 탭 녹화 회귀 검증.
- 영상 시간 범위·중복 장면·최대 길이·취소·재시작·실패·동시 작업·삭제 검증.
- 영상 근거 위조, 미검토 확정, 생성 중 근거 변경을 차단하는지 검증.
- 실제 ffmpeg와 로컬 vision 모델의 이미지 입력·출력·처리 시간을 측정.
- 브라우저 시연은 합성 카메라 자동 시험과 실제 사용자의 카메라 확인을 구분한다.
- 기존 전체 테스트와 빌드를 통과한 후 현재 실행본에 반영한다.
