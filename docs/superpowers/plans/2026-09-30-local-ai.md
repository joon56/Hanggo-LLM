# Local AI implementation plan

> Execute with subagent-driven-development. User authorized model recommendation, installation and local integration without another approval pause.

**Goal:** Run all four Hanggo text features and Korean speech transcription on this Windows PC without API credits.

**Architecture:** Keep existing domain validation and approval flows. Select OpenAI or Ollama at the server boundary; local mode never falls through to a cloud service. Use a local Whisper executable for audio. Models/binaries remain ignored local assets.

**Constraints:** RTX 4060 Laptop 8GB, RAM 32GB. Ollama 0.34.4 already installed. Preserve existing qwen2.5:3b and bge-m3. Bind only loopback. Do not expose secrets. Preserve source quotes, risk flags, refusal/incomplete rejection, cancellation, and manual fallbacks.
