# 자동 시연 자료

`dog.webm`은 [German shepherd eating dog treat](https://commons.wikimedia.org/wiki/File:German_shepherd_eating_dog_treat.webm)(Shadster, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0))의 크기를 640×360, 15fps로 줄이고 소리를 뺀 것이다. 라이선스는 원본과 같다.

자동 시연(`e2e/auto-demo.ts`)에서 보호자 카메라를 대신한다. 실제 상담 자료가 아니다.
